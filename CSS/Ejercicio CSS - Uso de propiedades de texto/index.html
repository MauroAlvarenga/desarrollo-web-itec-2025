Propiedades de los Textos

Las propiedades de texto en CSS permiten controlar el aspecto y el diseño del texto en una pagina web. A continuación, se describen algunas de estas propiedades:

Text-Indent

La propiedad text-indent se utiliza para establecer el desplazamiento de la primera linea de un párrafo. Puede definirse en longitud (por ejemplo, "20px") o un porcentaje (por ejemplo, "10%").

Este es un ejemplo de texto con desplazamiento de la primera linea utilizando la propiedad text-indent. La primera línea está desplazada 30px.

Text-Align

La propiedad text-align se utiliza para alinear el texto en una caja. Los valores comunes son "left", "right", "center" y "justify".

Este es un ejemplo de texto está alineado a la derecha utilizando la propiedad text-align.

Text-Decoration

La propiedad text-decoration se utiliza para aplicar efectos de subrayado y tachado al texto. Los valores incluyen "none", "underline", "overline" y "line-through".

Este es un ejemplo de texto con subrayado utilizando la propiedad text-decoration.

Letter-Spacing

La propiedad letter-spacing se utiliza para ajustar el espacio entre caracteres en un texto. Puede definirse como "normal" o en una longitud específica.

Este es un ejemplo de texto con un espaciado de letras aumentado utilizando la propiedad letter-spacing. Los caracteres están separados por 3px.

Word-Spacing

La propiedad word-spacing se utiliza para ajustar el espacio entre palabras en un texto. Al igual que letter-spacing, puede definirse como "normal" o en una longitud específica.

Este es un ejemplo de texto con un espaciado de palabras aumentado utilizando la propiedad word-spacing. Las palabras están separadas por 10px.

Text-Transform

La propiedad text-transform se utiliza para controlar la capitalización del texto. Los valores incluyen "uppercase", "lowercase", "capitalize" y "none".

Este es un ejemplo de texto transformado a mayúsculas utilizando la propiedad text-transform.

Line-Height

La propiedad line-height se utiliza para establecer la altura de las líneas de texto. Puede definirse como un número, una longitud o un porcentaje.

Este es un ejemplo de texto con una altura de línea aumentada utilizando la propiedad line-height. La altura de línea es de 70px.

Vertical-Align

La propiedad vertical-align se utiliza para alinear elementos en línea o en línea-bloque verticalmente. Los valores comunes son "baseline", "sub", "super", "top", "text-top", "middle", "bottom" y "text-bottom".

Este es un ejemplo de texto con alineacion vertical con una tabla usando vertical-align.

vertical-align: top; vertical-align: center; vertical-align: bottom;
