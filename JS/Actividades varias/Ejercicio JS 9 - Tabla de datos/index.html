Ejercicio - Manipulacion del DOM: Tabla de datos

Dado un array de objetos, donde cada objeto represente un "libro" con propiedades como titulo, autor y año, se genera una tabla HTML (table) dinámicamente con JavaScript, donde cada libro sea una fila (tr) y sus propiedades sean celdas (td). Añade una fila de encabezados (th) para la tabla.
